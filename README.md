## ⚡ 1-Click Installation on Any Machine

Move to a new laptop, desktop, VPS, or fresh installation? Set up your entire agent ecosystem in **30 seconds**:

### 🪟 Windows (PowerShell):
```powershell
git clone https://github.com/salomh46-rgb/jasper-master-skill.git
cd jasper-master-skill
.\install.ps1
```

### 🐧 Linux / 🍎 macOS (Bash):
```bash
git clone https://github.com/salomh46-rgb/jasper-master-skill.git
cd jasper-master-skill
bash install.sh
```

### 🐍 Universal Python Installer:
```bash
python installer.py [Optional_Path_To_Workspace]
```

#### What the installer does automatically:
1. Deploys all **44+ specialized skills** into `.agents/skills/`.
2. Installs the **Mega Master Skill** (`jasper-master-suite`).
3. Installs global agent rules (`GEMINI.md` for Antigravity & `CLAUDE.md` for Claude Code).
4. Generates an auto-indexed `skills-lock.json` manifest.
5. Injects production context templates (`PROJECT_CONTEXT.md` and `INFRASTRUCTURE_REGISTRY.md`).
